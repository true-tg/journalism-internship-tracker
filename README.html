Реєстр стажування • Setup Guide

Головна Адмінка

1. Про систему

Це мінімалистична система для проведення відбору на стажування з публічним табло в реальному часі та закритою адміністративною панеллю. Архітектура побудована на статичних файлах (HTML + Tailwind CSS + Alpine.js) та безсерверній базі даних Supabase (PostgreSQL + WebSockets).

2. Структура репозиторію

  • 📁 /index.html — публічна сторінка рейтингу з плавними анімаціями переміщення рядків.
  • 📁 /admin.html — панель керування (додавання кандидатів, швидке редагування балів, видалення).
  • 📁 /README.html — інструкція з розгортання проєкту.

3. Налаштування бази даних (Supabase)

  1. Створіть безкоштовний акаунт на supabase.com та створіть новий проєкт.
  2. Перейдіть у розділ SQL Editor і виконайте запит для створення таблиці `candidates`: 
    create table candidates (
  id bigint generated by default as identity primary key,
  name text not null,
  media text not null,
  stage1 numeric default 0,
  stage2 numeric default 0,
  stage3 numeric default 0
);
  3. Увімкніть публічний доступ (Realtime) для таблиці: перейдіть у Database ➔ Replication і додайте таблицю candidates до публічного потоку.
  4. У налаштуваннях проєкту (Project Settings ➔ API) скопіюйте Project URL та ключ anon public.

4. Підключення ключів у коді

Відкрийте файли index.html та admin.html і знайдіть наприкінці в секції скриптів рядки конфігурації: 

const SUPABASE_URL = 'ВАШ_PROJECT_URL';
const SUPABASE_ANON_KEY = 'ВАШ_ANON_KEY';

Замініть заглушки на ваші реальні дані з кабінету Supabase.

5. Публікація на GitHub Pages

  1. Завантажте файли index.html, admin.html та README.html у ваш репозиторій на GitHub.
  2. Перейдіть у налаштування репозиторію (Settings ➔ Pages).
  3. У блоці Build and deployment виберіть гілку main (або master) та кореневу папку / (root).
  4. Збережіть налаштування. Через хвилину сайт буде доступний за посиланням, яке з'явиться у цьому ж розділі.
